# Rainfall_Prediction_Web_App
# 🌧️ RainSense AI - Rainfall Prediction Web Application

An end-to-end Machine Learning web application that predicts whether it will rain tomorrow based on today's weather conditions.

Built using **Python, Flask, Scikit-learn, Pandas, NumPy, HTML, CSS, and Random Forest Classifier**.

## 📌 Project Overview

RainSense AI is a machine learning-powered web application that predicts the probability of rainfall for the next day using historical weather data.

The project covers the complete machine learning workflow:

- Data Preprocessing
- Feature Engineering
- Label Encoding
- Feature Scaling
- Model Training
- Model Evaluation
- Model Serialization
- Flask Web Deployment

---

## ✨ Features

- Predicts rainfall for the next day
- Displays prediction confidence
- User-friendly web interface
- Trained using Random Forest Classifier
- Flask-based backend
- Responsive design
- Fast predictions

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/mohdmubeen3/Rainfall_Prediction_Web_App.git
```

Go inside the project

```bash
cd Rainfall_Prediction_Web_App
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
